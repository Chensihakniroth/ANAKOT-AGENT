**The self-evolving AI agent built by [callmemo](https://callmemo.ai).** Anakot is high-performance, self-improving, and designed for seamless task automation and complex digital orchestration. Engineered with a focus on reliability and adaptability, Anakot bridges the gap between large language models and real-world execution.

Anakot isn't just a chatbot—it's an autonomous operator that manages local file systems, interacts with web browsers, and handles end-to-end workflows.

## 🚀 Key Features

- **Autonomous Problem Solving**: Anakot executes tasks from start to finish, managing your environment and tools autonomously.
- **Dynamic Skill System**: Built-in support for "Skills" that allow the agent to learn new capabilities on the fly and refine them through usage.
- **Multi-Platform Gateway**: Reach your agent anywhere via **Discord**, **Telegram**, **Slack**, and **WhatsApp**.
- **Local Host AI Priority**: Optimized for privacy and cost with native support for **LM Studio** and **Ollama**.
- **Sleek Web Dashboard**: A modern UI for monitoring sessions, managing configurations, and visualizing performance analytics.
- **Self-Improvement Loop**: Automatically analyzes session data to improve its own prompts and execution strategies.

## 🛠 Getting Started

### Quick Install (Linux, macOS, WSL2)

```bash
curl -fsSL https://anakot-agent.callmemo.ai/install.sh | bash
```

### Windows Setup
Native Windows is supported via the setup script in this repository. Open PowerShell as Administrator and run:

```powershell
./install-anakot.ps1
```
